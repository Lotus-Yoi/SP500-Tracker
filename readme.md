## 目前实现

- 从 FRED 获取 S&P 500 数据
- 清洗缺失数据
- 计算每日收益率
- 自动检测并更新最新数据
- 网络请求失败自动重试（这里折腾了我半天 qwq）
- 使用 Matplotlib 画图
